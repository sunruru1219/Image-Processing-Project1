# Image-Processing-Project1
MATLAB implementation of image processing algorithms, including noise reduction (average/median filter), edge sharpening, and image brightness enhancement/reduction (power law transformation/histogram equalization)

---

## 📌 Project Overview

This project showcases fundamental digital image processing algorithms built from the ground up in MATLAB. It focuses on spatial domain manipulation, enhancement techniques, and noise reduction strategies commonly applied in computer vision and software engineering workflows.

---

## 🚀 Implemented Features

### 1. Noise Reduction
* **Average Filter (Mean Filtering):** Blurs images to reduce random noise using local spatial averaging.
* **Median Filter:** Effective non-linear filtering method specifically for removing salt-and-pepper noise while preserving sharp edges.

### 2. Edge Sharpening
* High-frequency emphasis and derivative-based spatial operators to detect edges, highlight fine image details, and improve overall image clarity.

### 3. Brightness Adjustment
* **Power-Law (Gamma) Transformation:** Adjusts dynamic range to brighten dark regions or dim overly bright highlights non-linearly ($\gamma < 1$ or $\gamma > 1$).
* **Histogram Equalization:** Enhances global contrast by redistributing pixel intensity frequencies.
